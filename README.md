# 简历字段助手（Edge 扩展）

这是一个无需发布到扩展商店、可直接在 Microsoft Edge 中加载的本地扩展。它会在普通网页右侧显示一个常驻悬浮侧栏，用于管理、搜索和复制网申常用字段。

## 安装

1. 打开 Edge，在地址栏输入 `edge://extensions/`。
2. 打开页面左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择解压后的项目文件夹（其中应直接包含 `manifest.json`）。
5. 打开或刷新网申网页。

新打开或刷新的网页默认不显示侧栏。点击扩展按钮会先打开控制窗口，其中显示版本、套装数量和套装选择；点击“显示固定侧栏”后才会在网页中显示侧栏。快捷键 `Alt+Shift+R` 可直接显示或隐藏。Edge 设置页、扩展商店、新标签页等受保护页面不允许扩展显示，这是浏览器自身限制。

如果普通网页尚未加载扩展脚本，点击扩展按钮会自动注入并显示侧栏，不再要求先手动刷新页面。遇到浏览器明确禁止注入的页面时，扩展图标会显示红色 `!`。

字段区采用紧凑的双列布局：鼠标停在任意字段名称上会显示完整内容；点击蓝色字段名称会复制内容，点击灰色字段名称会打开内容弹窗，铅笔按钮用于编辑。标题栏的 `↕` 按钮可将侧栏一键贴到右侧并充满浏览器高度；最小化后只保留一个蓝色 `CV` 图标，点击图标即可恢复。

插件会隔离编辑框中的键盘事件，避免网申页面接管 Backspace、Delete、复制、粘贴或撤销等操作。

新增或编辑字段后会保留当前滚动位置。字段左侧的 `⠿` 是拖动手柄，可在同一板块内调整顺序，也可以把字段拖到其他板块；板块标题左侧的 `☰` 可拖动整个板块调整顺序。移动后的顺序会自动保存在本地。

工具栏提供“导航”按钮。点击后会在主侧栏外侧弹出一个独立的固定板块导航面板，点击板块名称即可平滑跳转；滚动内容时会自动标记当前所在板块。再次点击“导航”可收起面板，主侧栏移动或缩放时导航面板会自动跟随定位。

每个板块标题旁都有复制按钮，会把整个板块复制成 Markdown。切换到另一个套装后，将内容粘贴进“批量导入”；不含 `# 套装`、只有 `## 板块` 的内容会直接追加到当前套装。

套装、字段和修改记录会在多个网页之间自动同步；工具栏的“刷新”可用于手动读取最新数据，同时保留当前页面侧栏的位置、大小与滚动位置。“记录”页面按时间倒序保存最近 300 条操作，只记录套装、板块、字段及操作类型，不记录字段的具体内容。

从 v1.4.0 开始，共享简历数据与侧栏界面状态分别存储。移动、缩放、隐藏侧栏或切换套装不会再用某个网页中的旧副本覆盖其他网页刚保存的数据。如果正在编辑时检测到其他页面的更新，扩展会阻止旧编辑窗口直接覆盖新数据，并在关闭窗口后自动同步。

## Markdown 批量导入格式

```markdown
# 套装: 产品经理校招

## 基本信息
- [复制] 姓名: 张三
- [复制] 手机号: 13800000000
- [展示] 可入职时间: 一个月内

## 教育经历
- [复制] 学校名称: 示例大学
- [复制] 专业名称: 信息管理与信息系统
- [展示] 就读时间: 2020.09 - 2024.06

## 实习经历
- [复制] 公司名称: 示例科技有限公司
- [复制] 实习成果:
  负责用户研究与需求分析，推动 3 项功能上线。
  上线后核心流程转化率提升 12%。
- [展示] 实习时间: 2023.06 - 2023.08
```

规则：

- `# 套装: 名称`：创建一个岗位套装。
- `## 名称`：创建一个板块。
- `- [复制] 字段名: 内容`：点击内容即可复制。
- `- [展示] 字段名: 内容`：只用于查看提示，不触发复制。
- 长内容写在字段下一行，并至少缩进两个空格；可连续写多行。
- 如果内容从富文本界面复制后全部挤成一行，甚至标记之间没有空格，导入器也会根据标题和 `[复制]`、`[展示]` 标记自动恢复结构。
- 每次 Markdown 导入都会新增一个套装，不覆盖已有套装。

## 数据与隐私

所有内容只保存在 Edge 的本地扩展存储中，不会上传到网络。可以在“管理”中导出 JSON 备份，换电脑或重新安装后再导入。

仓库中的导入模板只包含虚构示例信息。请勿将包含真实姓名、电话、邮箱或履历的个人备份提交到公开仓库。
